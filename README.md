# Лабораторна робота №1: Ігрова кімната 
Янов Владислав ІПС-32

Цей проєкт є консольним Java-додатком, який реалізує симуляцію ігрової кімнати. Проєкт розроблено для демонстрації базових принципів об'єктно-орієнтованого програмування (ООП): інкапсуляції, успадкування, поліморфізму та абстракції.

* **Мова:** Java 21
* **Збірка:** Maven
* **Тестування:** JUnit 5, Mockito

## Функціонал
1. Базовий абстрактний клас `Toy`, проміжні категорії (`EducationalToy`, `CollectibleToy`) та конкретні реалізації (`Lego`, `Figurine`, `ScaleModel`).
2. Дані про іграшки зчитуються з файлу `toys_data.csv`.
3. Якщо загальна вартість іграшок перевищує заданий бюджет, викидається користувацький виняток `BudgetExceededException`.
4. Іграшки в кімнаті можна сортувати за ціною (через `Comparator`).
5. Реалізовано пошук іграшок за параметрами (наприклад, за ціною та розміром) з використанням функціональних інтерфейсів (`Predicate`).
6. покриття бізнес-логіки, парсера та моделей Unit-тестами.

## Структура проєкту
Код розділено на пакети згідно з Java Code Conventions:
* `oop_lab1.model` — класи даних (моделі іграшок та перерахування `Size`).
* `oop_lab1.service` — бізнес-логіка (завантаження, сортування, пошук).
* `oop_lab1.util` — утиліти (інтерфейс та реалізація зчитування з CSV).
* `oop_lab1.exception` — власні класи винятків.
